# AutoCheck — 表格数据体检与波动归因工具

输入一张表（CSV / Excel / SQL 导出），自动完成数据质量校验、趋势与突变检测、波动归因下钻、
动态阈值预警、重复与高频行为识别、流程漏斗分析，并输出一份可复核的结构化报告。

核心原则：**代码算数，模型写话**——报告中所有数字由 pandas 确定性计算，大模型仅基于事实清单撰写结论，
不参与任何数值计算。

- **技术栈**：Python · pandas · Streamlit · OpenAI 兼容接口（可选）
- **运行方式**：网页版（拖拽上传）/ 命令行
- **当前状态**：7 类检查全部实现，内置 3 组带真值的测试样本，检出结果与预期一致

## 设计原则

1. **确定性计算与语言生成分离**：金额、环比、阈值、转化率全部由 pandas 计算；模型只读取"事实清单"写结论，禁止自行推算。这从结构上排除了模型编造数字的可能。
2. **可解释、可溯源**：每条异常都附带证据（哪一行、超出多少、阈值是多少），结论可逐条复核。
3. **无异常也出报告**：输出的是"体检报告"而非"警报器"，明确写出未发现的问题；断网或无 API Key 时自动降级为规则模板，功能不中断。

## 检测能力

| 检查项 | 内容 | 实现方式 |
|---|---|---|
| 数据质量 | 缺失率、完全重复行、负金额、空值、极端大额 | 规则校验 |
| 趋势与突变 | 按周聚合，周环比超过 ±25% 自动标注 | 周粒度聚合 + 阈值 |
| 波动归因 | 峰值期与上周对比：量价拆解，并按原因 / 渠道 / 星级下钻定位主因 | 贡献度拆解 |
| 动态阈值预警 | 滚动 7 日均值 + 2σ，超限自动标记 | 滚动统计 |
| 重复与高频识别 | 同一订单多次发生；同一主体 30 天内 ≥3 次 | 分组计数 |
| 流程漏斗 | 各环节转化率逐级计算 | 阶段计数 |
| 结论与建议 | 规则模板（离线）/ 大模型（配置 Key 后） | 可选增强 |

**列名自动识别**：支持中英文常见字段名（如 `赔付金额` / `amount`、`订单号` / `order_id`、`状态` / `status`），
识别不到的字段会跳过，并在报告的"口径说明"中明确写出被忽略的列，不会因字段缺失而报错。

## 报告结构

| 章节 | 内容 |
|---|---|
| 摘要解读 | 用 3–5 句话说明"这张表主要有什么问题、应该先查什么" |
| 检查项详情 | 逐项给出数字证据与判定依据 |
| 问题数据明细 | 直接列出有问题的具体记录（负数金额、空值、大额单、重复记录、高频记录等），网页版支持排序与筛选 |
| 附表 | 周趋势、归因下钻、触发阈值的日期、漏斗各环节 |

## 快速开始

### 方式一：网页版

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 http://localhost:8501，上传 `sample_data/` 下的示例表，点击开始体检。
Windows 下也可直接双击 `启动-网页版.bat`。

### 方式二：命令行

```bash
# 规则模式（无需任何 Key）
python main.py "sample_data/赔付明细_示例.csv" --out "示例报告.md"

# 启用大模型生成结论（需配置 .env）
python main.py 你的表.csv --llm --out 报告.md
```

也可双击 `命令行demo.bat` 直接查看效果。

### 配置

| 文件 | 用途 |
|---|---|
| `config.json`（可选） | 表名、列名映射、检查阈值；参考 `config.example.json` 复制修改 |
| `.env`（可选） | 大模型配置，参考 `.env.example` |

```ini
LLM_BASE_URL=https://api.deepseek.com/v1   # 也可指向本地 Ollama: http://localhost:11434/v1
LLM_API_KEY=sk-xxx
LLM_MODEL=deepseek-chat
```

未配置 Key 时自动使用规则模板，报告照常生成；命令行加 `--llm` 或网页版选择大模型模式即可启用 AI 结论。

## 设计取舍

| 决策点 | 采用方案 | 放弃的方案 | 原因 |
|---|---|---|---|
| 数值计算 | pandas 确定性计算 | 让模型直接读表并生成结论 | 模型算数不可靠且不可复核；分离后结论可逐条溯源 |
| 异常判定阈值 | 滚动 7 日均值 + 2σ 动态阈值 | 固定阈值 | 业务量存在周期波动，固定阈值在旺季会持续误报 |
| 归因方式 | 量价拆解 + 维度下钻（原因/渠道/星级） | 直接让模型给归因结论 | 拆解过程可验证，先定位到具体维度再请模型组织语言 |
| 无异常场景 | 明确输出"未发现问题" | 仅在有异常时输出 | 避免"没报警"与"没检测"混淆，误报率可被验证 |
| 交互形态 | Streamlit 网页版 + CLI 双入口 | 只做网页版 | 批量与定时场景下命令行更易集成 |

## 已知限制

- 动态阈值依赖滚动窗口样本量，数据不足 14 天时阈值不稳定，建议至少一个月数据
- 归因采用量价拆解与维度下钻，未做统计显著性检验，结论属于经验判断而非因果推断
- 单表处理，未接入数据库直连与定时巡检
- 大模型结论仅基于事实清单撰写，不能发现清单之外的异常
- 列名自动识别依赖内置别名表，业务字段命名差异较大时需手工配置映射
